# RUAccent

RUAccent - это библиотека для автоматической расстановки ударений на русском языке.

**Мы переходим на лицензию MIT для всей системы v1.**

## Установка
   С помощью pip
   ```
   pip install ruaccent
   ```
   С помощью GIT
   ```
   pip install git+https://github.com/Den4ikAI/ruaccent.git
   ```
## Параметры работы

    load(omograph_model_size='turbo2', use_dictionary=True, custom_dict={}, device="CPU", workdir=None, yo_exclude=None, mark_polysyllables=False)

 - На данный момент доступно 6 моделей - **tiny**, **tiny2**, **tiny2.1**, **turbo2**, **turbo3**, **turbo3.1**, **turbo**, **big_poetry**.
 - Переменная **use_dictionary** отвечает за загрузку всего словаря (требуется больше ОЗУ), иначе все ударения расставляет нейросеть. 
 - Функция **custom_dict** отвечает за добавление своих вариантов ударений в словарь. Формат такой: `{'слово': 'сл+ово с удар+ением'}`
- Выбор устройства CPU или CUDA. **Для работы с CUDA требуется установить onnxruntime-gpu и CUDA.**
- workdir - принимает строку. Является путём, куда скачиваются модели, словари и правила Козиева (папка `koziev`, 190 МБ кода и данных). Если `koziev` уже лежит в каталоге установленного пакета, как у прежних версий, используется он; иначе — `workdir/koziev`: окружения с общим `workdir` не скачивают его заново, а каталог пакета может быть доступен только для чтения (контейнеры).
- yo_exclude - список слов, которым ё не ставится никогда, хотя словари знают вариант с ё (по умолчанию `DEFAULT_YO_EXCLUDE`: «самое», «небо», «далеко», «лет», «узнаем»… — вариант с ё у них архаизм, редкость или фамилия, а модель выбирает его даже на целом предложении). `yo_exclude=[]` отключает список.
- mark_polysyllables - при True ударение получает каждое слово из двух и более слогов, что бы ни решила модель «нужно ли здесь ударение» (она оставляет без знака и часть знаменательных слов: «'Золотой ключик'»); за односложными словами решение остаётся за ней. Для синтеза речи: без знака TTS-модель ставит ударение наугад. Можно менять и после загрузки: `accentizer.mark_polysyllables = True`.
- tiny_mode - принимает True или False. При True отключает руловый пайплайн и часть моделей. Также не загружается словарь ударений.

    **Для стабильной работы требуется минимум 512 мегабайт ОЗУ (модель омографов - tiny)**

## Пример использования
```python
from ruaccent import RUAccent

accentizer = RUAccent()
accentizer.load(omograph_model_size='turbo3.1', use_dictionary=True, tiny_mode=False)

text = 'на двери висит замок.'
print(accentizer.process_all(text))
```

### skip_regex

```python
accentizer.process_all(text, skip_regex=r"[^\w\s]")
```

То, что совпало с `skip_regex`, возвращается без изменений — как и всё, что не является словом: текст сохраняет
свою пунктуацию и пробелы и получает только `+` и ё. Модели при этом читают предложения целиком, вместе с
защищёнными фрагментами, поэтому ударения и ё те же, что и без `skip_regex`.

## Изменения в 1.5.8.4

- `process_all(..., skip_regex=...)` обрабатывал отрезки между совпадениями по одному, и модели видели только их:
  при защищённой пунктуации от «раньше, чем случилась трагедия» оставалось «чем случилась трагедия» → «чём».
  На 3000 фраз разговорной речи разметка отличалась от разметки без `skip_regex` у 4,4% слов, а среди
  ё-омографов («все»/«всё», «чем»/«чём») ё ошибочно ставилась в 28% случаев; теперь 0% и 3,4%. Заодно
  перестали пропадать пробелы между двумя соседними совпадениями («О, «Гамлет» — это» → «О,«Гамлет»— это»).
- Метки моделей сопоставлялись со словами по номеру, а токенизаторы моделей делят «»,» на два слова там, где
  `split_by_words` оставляет одно: в 2,5% предложений все слова после такого места получали метку соседа
  (и ё, и «ставить ли ударение»). Теперь — по позиции слова в предложении.
- Модель ё-омографов обучена на тексте без ё и получает его без ё (ложных ё: 14,7% → 11,7%).
- `yo_exclude` / `DEFAULT_YO_EXCLUDE`: «самое время» больше не «самоё», «левой рукой» — не «лёвой».
- `process_yo` удваивал пробел между предложениями и терял пробелы в конце.
- Правила Козиева (`koziev`) ищутся в каталоге пакета, затем в `workdir`, и скачиваются в `workdir`, а не в установленный пакет; при `tiny_mode=True` не скачиваются вовсе (они там не используются).
- `mark_polysyllables` — знак на каждом слове из двух и более слогов (для синтеза речи).
- Тесты без загрузки моделей: `pytest tests`.
